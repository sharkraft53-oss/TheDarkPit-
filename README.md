# TheDarkPit

> Atmospheric horror adventure game currently in development with Unity and C#.

## About

TheDarkPit is a personal atmospheric horror game project focused on exploration, darkness and environmental interaction.

The game uses a monochrome black, white and gray visual style to create a mysterious and unsettling atmosphere.

The player explores a dark world using a limited light source, interacts with the environment and encounters mysterious characters and locations.

**Status:** In Development

## Gameplay Features

- Character movement and exploration
- Interactive environment
- Handheld light system
- Light charging mechanics
- Movable generator mechanics
- Character animations
- Interaction system
- Atmospheric lighting and fog
- Side-view camera
- Indoor first-person sections
- Environmental storytelling

## Development

The project is being developed in **Unity using C#**.

I worked on gameplay programming, interaction systems, character mechanics, lighting, level design and implementation of the game's visual atmosphere.

### Technologies

- Unity
- C#
- Unity Input System
- HDRP
- Animation Rigging / IK
- Blender
